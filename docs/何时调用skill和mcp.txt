 1. Skill 调用场景

  Skill 是轻量级的分析能力，每次用户输入时自动调用。

  当前实现的两个 Skill：

  ① CrisisDetectorSkill (危机检测) - 每次必调用

  触发条件：用户每次发送消息

  用户输入: "我最近感觉很绝望，不想活了"
                      │
                      ▼
  ┌─────────────────────────────────────────┐
  │ CrisisDetectorSkill 自动执行             │
  │                                          │
  │ 检测关键词: "绝望"(+7分), "不想活"(+10分) │
  │ 计算风险分数: 17分                        │
  │ 判定风险等级: critical                    │
  └─────────────────────────────────────────┘
                      │
                      ▼
  返回结果:
  {
      "risk_level": "critical",
      "risk_score": 17,
      "intervention_needed": true,
      "intervention": {
          "immediate": true,
          "hotlines": [
              {"name": "全国心理援助热线", "number": "400-161-9995"}
          ]
      }
  }
                      │
                      ▼
  ResponseAgent 收到 risk_level="critical"
      → 使用危机干预模式生成回复
      → 自动附上求助热线

  具体例子：

  ┌──────────────────────┬─────────────────┬────────────────────┐
  │       用户输入       │    检测结果     │      系统行为      │
  ├──────────────────────┼─────────────────┼────────────────────┤
  │ "你好"               │ low (0分)       │ 正常对话           │
  ├──────────────────────┼─────────────────┼────────────────────┤
  │ "最近压力很大"       │ low (2分)       │ 正常对话           │
  ├──────────────────────┼─────────────────┼────────────────────┤
  │ "我很痛苦，快崩溃了" │ medium (4分)    │ 加强关注           │
  ├──────────────────────┼─────────────────┼────────────────────┤
  │ "我没有希望了"       │ high (7分)      │ 提供专业资源       │
  ├──────────────────────┼─────────────────┼────────────────────┤
  │ "我想自杀"           │ critical (10分) │ 立即干预，附上热线 │
  └──────────────────────┴─────────────────┴────────────────────┘

  ② EmotionAnalyzerSkill (情绪分析) - 可选调用

  触发条件：需要分析用户情绪倾向时

  用户输入: "今天工作很不顺利，被领导批评了，感觉很委屈"
                      │
                      ▼
  ┌─────────────────────────────────────────┐
  │ EmotionAnalyzerSkill 执行               │
  │                                          │
  │ 分析情绪分布:                            │
  │   - 委屈: 0.65                          │
  │   - 愤怒: 0.35                          │
  │   - 悲伤: 0.20                          │
  │ 主要情绪: 委屈                          │
  │ 强度: moderate                          │
  └─────────────────────────────────────────┘
                      │
                      ▼
  返回结果供 ResponseAgent 参考
      → 回复时针对"委屈"情绪给予支持

  2. MCP 调用场景

  MCP 是外部工具能力，需要明确的功能需求时才调用。

  三个 MCP 服务器：

  ① FilesystemMCP (文件系统)

  什么时候会调用？

  ┌────────────────────┬─────────────┬──────────────────────────────┐
  │        场景        │ 调用的工具  │             说明             │
  ├────────────────────┼─────────────┼──────────────────────────────┤
  │ 导出咨询报告       │ write_file  │ 将咨询记录保存为PDF/文本文件 │
  ├────────────────────┼─────────────┼──────────────────────────────┤
  │ 读取用户上传的文件 │ read_file   │ 用户上传了心情日记等文件     │
  ├────────────────────┼─────────────┼──────────────────────────────┤
  │ 管理存储文件       │ list_files  │ 列出用户保存的记录           │
  ├────────────────────┼─────────────┼──────────────────────────────┤
  │ 删除过期数据       │ delete_file │ 清理旧数据                   │
  └────────────────────┴─────────────┴──────────────────────────────┘

  例子：生成咨询报告
  用户: "请帮我生成一份我的咨询记录报告"
                      │
                      ▼
  ┌─────────────────────────────────────────┐
  │ ToolAgent 调用 FilesystemMCP            │
  │                                          │
  │ tool_calls: [{                          │
  │   "server": "filesystem",               │
  │   "tool": "write_file",                 │
  │   "params": {                           │
  │     "path": "reports/user_001.txt",     │
  │     "content": "咨询报告内容..."         │
  │   }                                     │
  │ }]                                      │
  └─────────────────────────────────────────┘
                      │
                      ▼
  文件保存成功，返回文件路径给用户

  ② DatabaseMCP (数据库)

  什么时候会调用？

  ┌──────────────┬────────────────────┬──────────────────────────┐
  │     场景     │     调用的工具     │           说明           │
  ├──────────────┼────────────────────┼──────────────────────────┤
  │ 查看历史对话 │ query_user_history │ 用户问"上次我们聊了什么" │
  ├──────────────┼────────────────────┼──────────────────────────┤
  │ 保存会话记录 │ save_conversation  │ 持久化当前对话           │
  ├──────────────┼────────────────────┼──────────────────────────┤
  │ 记录危机事件 │ log_crisis_event   │ 用户表达自杀念头时记录   │
  └──────────────┴────────────────────┴──────────────────────────┘

  例子：查询历史对话
  用户: "上次你给我推荐的那个放松方法是什么？"
                      │
                      ▼
  ┌─────────────────────────────────────────┐
  │ ToolAgent 调用 DatabaseMCP              │
  │                                          │
  │ tool_calls: [{                          │
  │   "server": "database",                 │
  │   "tool": "query_user_history",         │
  │   "params": {                           │
  │     "user_id": "user_001",              │
  │     "limit": 10                         │
  │   }                                     │
  │ }]                                      │
  └─────────────────────────────────────────┘
                      │
                      ▼
  返回历史对话记录
      → ResponseAgent 从中找到之前推荐的放松方法

  ③ SearchMCP (搜索引擎)

  什么时候会调用？

  ┌────────────┬────────────────────────┬────────────────────────┐

  3. 完整调用流程示例

  场景一：正常咨询（只调用 Skill）

  用户输入: "最近工作压力很大，经常失眠"
                      │
      ┌───────────────┼───────────────┐
      ▼               ▼               ▼
  IntentAgent    SkillAgent       RAGAgent
  (意图识别)      (危机检测)        (知识检索)
      │               │               │
      │          检测结果:            │
      │          risk_level=low       │
      │          无危机信号           │
      │               │               │
      └───────────────┼───────────────┘
                      ▼
              ResponseAgent
              (生成回复)
                      │
                      ▼
  回复: "听起来工作压力确实影响了你的睡眠..."

  ✅ 调用了 Skill (危机检测)
  ❌ 没有调用 MCP (不需要文件/数据库操作)

  场景二：危机干预（Skill + MCP）

  用户输入: "我已经坚持不下去了，想结束这一切"
                      │
      ┌───────────────┼───────────────┐
      ▼               ▼               ▼
  IntentAgent    SkillAgent       RAGAgent
      │               │               │
      │          检测结果:            │
      │          risk_level=critical  │
      │          ⚠️危机信号!         │
      │               │               │
      │               ▼               │
      │         自动触发 MCP:         │
      │         DatabaseMCP           │
      │         log_crisis_event      │
      │         (记录危机事件)         │
      │               │               │
      └───────────────┼───────────────┘
                      ▼
              ResponseAgent
              (危机干预模式)
                      │
                      ▼
  回复: "我非常关心你现在的状态...
        请立即联系专业帮助:
        全国心理援助热线: 400-161-9995"

  ✅ 调用了 Skill (危机检测)
  ✅ 调用了 MCP (记录危机事件到数据库)

  场景三：请求历史记录（MCP）

  用户输入: "帮我看一下我过去一个月的咨询记录"
                      │
      ┌───────────────┼───────────────┐
      ▼               ▼               ▼
  IntentAgent    SkillAgent      ToolAgent
  (意图识别)      (常规检测)       (调用MCP)
      │               │               │
      │               │          调用: database
      │               │          工具: query_user_history
      │               │          参数: {user_id, days: 30}
      │               │               │
      └───────────────┼───────────────┘
                      ▼
              ResponseAgent
              (整理记录展示给用户)

  ✅ 调用了 Skill (常规检测)
  ✅ 调用了 MCP (查询数据库)

  4. 总结对比

  ┌──────────┬──────────────────────┬────────────────────────────┐
  │   特性   │        Skill         │            MCP             │
  ├──────────┼──────────────────────┼────────────────────────────┤
  │ 调用时机 │ 每次用户输入自动调用 │ 按需调用                   │
  ├──────────┼──────────────────────┼────────────────────────────┤
  │ 主要用途 │ 分析、检测、评估     │ 文件操作、数据库、搜索     │
  ├──────────┼──────────────────────┼────────────────────────────┤
  │ 执行位置 │ 内存中计算           │ 外部系统交互               │
  ├──────────┼──────────────────────┼────────────────────────────┤
  │ 是否阻塞 │ 轻量，不阻塞         │ 可能有IO延迟               │
  ├──────────┼──────────────────────┼────────────────────────────┤
  │ 当前实现 │ 危机检测、情绪分析   │ 文件系统、数据库、搜索引擎 │
  └──────────┴──────────────────────┴────────────────────────────┘

  简单记忆：
  - Skill = 智能分析能力（每次都用）
  - MCP = 外部工具能力（需要才用）
